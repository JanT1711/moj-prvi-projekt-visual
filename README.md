# moj-prvi-projekt-visual

## Skilli za spletne strani

Izdelani iz vzorca spletne publikacije *Uspešna Slovenija* (»Vzorec B«).

| Mapa | Kaj vsebuje |
|---|---|
| `skills/uspesna-slovenija-splet/` | oblikovni sistem spletne publikacije SBC Uspešna Slovenija: barve, pisave, tipografska lestvica, komponente, predloge strani, vsebinski model; `references/osnovni.css` in delujoča predloga `references/predloga.html` |
| `skills/postavitev-spletne-strani/` | postopek od briefa do objave: katalog postavitev (časopisna po vzoru FT, mnenjska, institucionalna, pristajalna, ponudba), prenos sloga iz vzorca, objava, pravne obveznosti v Sloveniji |
| `skills/urednistvo-novic-azn/` | uredniški pult Novice AZN: podatkovni model, objava in urejanje člankov prek baze, fotografije, naslovnica, nadgradnja kode (izvor + skripta za gradnjo) |
| `skills/prepis-avdia-slovenscina/` | prepis posnetkov v slovensko besedilo: strojni prepis (faster-whisper), prompt strokovnjaka za slovenski jezik (lektor, redaktor, korektor), pogoste napake, oblika oddaje |
| `skills/spletne-strani/` | splošna pravila za spletne strani: arhitektura, odzivnost, dostopnost, SEO, partnerji, preizkus |
| `skills/posodobljeni/` | celotne posodobljene različice obstoječih skillov (`oblikovalec-sbc`, `sbc-revija-slog`, `urednik-sbc`, `oblikovalec`, `dizajn-iz-html`) z že vnesenimi dopolnili |
| `.claude/skills/` | nova skilla, ki se v tem repozitoriju v Claude Code naložita samodejno |
| `skills/dopolnila-obstojecih.md` | bloki za dopolnitev obstoječih skillov (`oblikovalec-sbc`, `sbc-revija-slog`, `urednik-sbc`, `oblikovalec`, `dizajn-iz-html`) |
| `skills/zip/` | 10 ZIP paketov za nalaganje v claude.ai (Nastavitve → Skills → Naloži); posodobljeni zamenjajo obstoječe skille z istim imenom |
