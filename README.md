## Skilli za spletne strani

Izdelani iz vzorca spletne publikacije *Uspešna Slovenija* (»Vzorec B«).

| Mapa | Kaj vsebuje |
|---|---|
| `skills/uspesna-slovenija-splet/` | oblikovni sistem spletne publikacije SBC Uspešna Slovenija: barve, pisave, tipografska lestvica, komponente, predloge strani, vsebinski model; `references/osnovni.css` in delujoča predloga `references/predloga.html` |
| `skills/spletne-strani/` | splošna pravila za spletne strani: arhitektura, odzivnost, dostopnost, SEO, partnerji, preizkus |
| `skills/dopolnila-obstojecih.md` | bloki za dopolnitev obstoječih skillov (`oblikovalec-sbc`, `sbc-revija-slog`, `urednik-sbc`, `oblikovalec`, `dizajn-iz-html`) |
| `skills/zip/` | ZIP paketa za nalaganje v claude.ai (Nastavitve → Skills → Naloži) |
