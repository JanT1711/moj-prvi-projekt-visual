# Reference

Strani, ki so mi všeč kot zgled za oblikovanje. Shranjene so kot vir za študij
sloga in strukture, ne za kopiranje vsebine ali blagovne znamke.

## festival-sbc.html

5. Festival podjetništva SBC (10. 11. 2026, Brdo pri Kranju).
Izvor: https://claude.ai/artifact/2KpTd4mm66nnwix21GidZC

Kopija vsebuje HTML, CSS in JavaScript strani. Slike govorcev, fotografije in
video niso vključeni, zato so ta mesta v lokalni kopiji prazna.

Kaj mi je všeč: celoten koncept.

- **Ena vizualna ideja nosi vse.** Šest barvnih stolpcev iz ključne podobe se
  ponovi v ikoni, mini grafu v glavi, ozadju portretov in animaciji
  "stolpci zrastejo iz tal".
- **Barva = pomen.** Vsako poglavje ima svojo barvo, ki vedno pomeni isto;
  teal je samo za gumbe in trak z datumom.
- **Struktura sledi vsebini.** Stran je zgrajena kot festivalski dan (odprtje,
  vprašanje dneva, program, govorci, praktično, prijava), ne kot generična predloga.
- **Pravila so zapisana na vrhu CSS-ja** (npr. besedilo nikoli neposredno na
  fotografiji, številke samo z resničnimi podatki, en napis za en namen).
- **Obrt:** tekoča tipografija, preverjen kontrast, svetla in temna tema,
  posebna mobilna postavitev, spoštovanje "manj gibanja", dve pisavi z jasnima
  vlogama (Sora za naslove, Open Sans za besedilo).
