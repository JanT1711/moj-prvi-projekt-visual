# Pogoste napake v strojnih prepisih slovenščine

## Napake razpoznave (preveri v kontekstu)
- **Podobno zveneče besede:** *vlada/vlaga*, *zavarovanje/za varovanje*, *odstotek/od stotek*, *pomoč/po moč*, *s tem/stem*, *kaj/kej*, *tudi/tut*.
- **Kratice in imena:** *AZN* → »a ZN«, *EIOPA* → »Evropa«, *SURS* → »surs«, *NLB* → »en el be«; osebna imena se pogosto zapišejo z malo začetnico ali napačno (*Zakrajšek* → »za krajšek«).
- **Števila:** »dva tisoč šestindvajset« → *2026*; »pet procentov« → *5 %* (v berljivi in uredniški ravni *odstotkov*); »tri komma pet milijona« → *3,5 milijona*.
- **Manjkajoče ali napačne končnice**, zlasti v dvojini (*dva zavarovanca*, *sta rekla*) in pri sklanjanju imen.
- **Zlepljene ali razbite besede:** *na primer* (ne *naprimer*), *čim prej*, *kljub temu*, *nenazadnje* / *ne nazadnje* (oboje dopustno, dosledno po hišnem slogu).
- **Ločila:** strojni prepis postavlja pike sredi misli in izpušča vejice pred *ki, ko, da, če, ker*.

## Pogovorno → knjižno (berljiva in uredniška raven)
| Govor | Knjižno |
|---|---|
| pol, potle | potem |
| js, jst | jaz |
| tko | tako |
| glih | ravno, prav |
| fajn | dobro, prijetno (ohrani v neposrednem slogu, če je del govorčevega sloga) |
| a ne, ne? (na koncu) | izpusti ali »kajne« |
| men | meni |
| bom šu | bom šel |
| un, una | tisti, tista |
| zdej | zdaj |
| kr, k | ker, ko (po pomenu) |
| mamo, mate | imamo, imate |

## Mašila, ki jih berljiva raven izpusti
*eee, mmm, hm, ne, pač, a veš, v bistvu* (kadar ne pomeni »v resnici«), *recimo* (kot mašilo), *tako da* (na začetku stavka brez pomena), ponovitve in zatikanja (*to je – to je bil*).

## Kalki in slogovne napake (uredniška raven; v dobesednih navedkih previdno)
- *izgleda* → *je videti*, *kaže*
- *nuditi* → *ponujati, dajati*
- *se nahaja* → *je, leži, stoji*
- *v kolikor* → *če*
- *s strani* + trpnik → tvorni stavek (*ministrstvo je sprejelo*)
- *tekom* → *med, v*
- *napram* → *do, proti, v primerjavi z*
- *koristiti* (v pomenu uporabljati) → *uporabljati*
- *baziran na* → *ki temelji na*
- *izvršiti, izvesti* (pretirano) → *opraviti, narediti*
- *na koncu dneva* → *navsezadnje*
- *narediti smisel* → *biti smiseln*

## Zapis po hišnem slogu (če naročnik nima svojega)
- Datum *16. 10. 2026*, ura *ob 9.30*, odstotek *5 %*, tisočice *23.000*, decimalna vejica *3,5*.
- Narekovaji »…«, navedek v navedku ›…‹; pomišljaj – s presledki; razpon *2020–2026* brez presledkov.
- Nazivi pred imenom z malo: *dr. Ana Novak*, *prof. dr. Janez Kos*; funkcije z malo: *predsednik vlade*, *direktorica agencije*.
- Ustanove z veliko le prva beseda (razen lastnih imen): *Agencija za zavarovalni nadzor*, *Ministrstvo za finance*, *Banka Slovenije*.
